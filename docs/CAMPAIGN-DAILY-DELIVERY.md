Require PostgreSQL, existing Brevo sender/key, CAMPAIGN_REPORT_DELIVERY_ENABLED=true and an explicitly approved recipient allowlist; then an authorized Admin saves a PKT schedule. No default recipient or automatic historical backlog. Unique date reservation prevents duplicate sends even across replicas; ambiguous failures and abandoned reservations require provider reconciliation before any resend.
