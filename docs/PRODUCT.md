# Game Arena Product

Game Arena is a mobile-first HTML5 gaming platform for Pakistan. Guests can discover and play selected games with minimal friction, then sign in by OTP when an account is required.

## Commercial model

- Free: selected catalogue, standard rewards, basic leaderboards and ad-supported play.
- Game Arena+: full catalogue, ad-free play, premium challenges, tournaments, reward eligibility, 2× Arena Coins and a 10% member top-up discount.
- Monthly: PKR 299.
- Yearly: PKR 4,999.

## Frontend scope

The release candidate includes swipe discovery, catalogue search, favourites, rewards, tournaments, OTP flows, JazzCash-ready checkout states, account settings, PWA installation and offline shell support.
